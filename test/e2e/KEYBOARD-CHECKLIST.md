# Client keyboard acceptance checklist

Run the client locally, then verify:

- Tab reaches the skip link.
- Enter on the skip link moves focus to `#main-content`.
- Tab reaches the search input and Search button.
- Enter submits the search form.
- Focus remains visible on all interactive elements.
- Search result links are keyboard reachable.
- No focus trap occurs.
- Result status is announced through `aria-live`.
